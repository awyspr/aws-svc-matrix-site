AWS Service Matrix

Which AWS services are live in which regions?

Our unofficial AWS Service Matrix builds a view from AWS' own public inventories and data feeds to show what is available where.

How it works
  • Green cell with dark green tick (✓) = service available in that region. White cell with grey dot (·) = service not available in that region.
  • Opt-in regions are marked in the header row with red text (default commercial regions are shown in black). Opt-in regions are not enabled in AWS accounts by default.
  • Search by keyword, service name or use multiple comma-separated terms across services and regions; combine with the filters to narrow the view.
  • Change badges +N/-N in the header row show how many services were added / removed for that region since the previous snapshot. Added service cells get a highlighted green border and the dark green tick; removed service cells get a highlighted red border and an X marker.
Data sources
  • AWS Systems Manager global-infrastructure parameters — service × region matrix, region metadata.
  • AWS Regional Product Services — cross-check + service doc URLs.
  • AWS Products directory — categories, launch dates.
  • Data is fetched daily on a best-effort basis from public AWS endpoints and may lead or lag official announcements.
What this tool is not
  1. This is about service availability (is service X in region Y?), not service health or status (is service X working right now?). For live health and incident information, see health.aws.amazon.com/health/status.
  2. This is about service availability (is service X in region Y?), not region-suitability for a workload (should I put my X in region Y?) and not about pricing (how much does it cost?). Consult AWS documentation and pricing pages for those questions.
  3. This tool only covers the AWS commercial partition. It does not analyse isolated regions, GovCloud regions, European sovereign cloud regions, or China regions.
